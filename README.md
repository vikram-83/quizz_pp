# 🧠 Quiz App

A responsive Quiz Application built using HTML, CSS, and JavaScript. Users can answer multiple-choice questions, view their score, and restart the quiz.

## 🚀 Features

- Multiple-choice questions
- Instant answer selection
- Score calculation
- Next question navigation
- Final result screen
- Restart quiz option
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Quiz-App/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
